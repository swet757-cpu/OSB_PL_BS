# Управленческий баланс из ОСВ

Проект формирует управленческий баланс из оборотно-сальдовой ведомости `.xlsx`.

## Быстрый запуск

1. Выгрузите ОСВ из 1С в формате `.xlsx`.
2. Положите файл в папку `01_ОСВ_входящие`.
3. Запустите команду:

```powershell
python .\generate_report.py
```

4. Готовый отчет появится в папке `02_Готовые_отчеты`.

## Что формируется

В отчете создаются листы:

- `Отчет` - управленческий баланс.
- `Расчет капитала` - понятная расшифровка собственного капитала.
- `Детализация ОСВ` - строки ОСВ, которые попали в расчет.
- `Настройка строк` - какие счета используются для каждой строки баланса.

## Логика управленческого баланса

Баланс строится по формуле:

```text
Активы = Обязательства + Собственный капитал
```

Собственный капитал раскрывается так:

```text
Собственный капитал = Уставный капитал + Накопленная прибыль / убыток
```

Накопленная прибыль / убыток считается как балансирующая строка:

```text
Накопленная прибыль / убыток = Активы - Обязательства - Уставный капитал
```

## Основные настройки

Настройки строк находятся в файле:

```text
04_Настройки\report_lines.json
```

В текущей версии отдельно выделяются:

- деньги;
- авансы поставщикам;
- дебиторская задолженность покупателей;
- подотчетные лица;
- переплаты по налогам;
- переплаты по страховым взносам;
- запасы, товары и незавершенное производство;
- внеоборотные активы;
- задолженность перед поставщиками;
- авансы покупателей;
- налоги к уплате;
- страховые взносы к уплате;
- кредиты и займы;
- уставный капитал;
- накопленная прибыль / убыток.

## Важно про GitHub

Реальные ОСВ и готовые отчеты могут содержать финансовые данные компании. Поэтому папки `01_ОСВ_входящие` и `02_Готовые_отчеты` исключены из публикации через `.gitignore`.

Подробная инструкция для пользователя находится в файле `ИНСТРУКЦИЯ.md`.
