# Инструкция: как сформировать управленческий баланс из ОСВ

## 1. Что делает файл

Скрипт `generate_report.py` берет оборотно-сальдовую ведомость из папки `01_ОСВ_входящие` и формирует управленческий баланс в Excel.

Итоговый баланс показывает:

- активы компании;
- обязательства компании;
- собственный капитал;
- уставный капитал отдельно;
- накопленную прибыль или убыток как расчетную строку;
- отдельные строки по налогам и страховым взносам.

## 2. Как подготовить ОСВ

1. В 1С сформируйте ОСВ.
2. Выгрузите ее в Excel, формат `.xlsx`.
3. Поместите файл в папку:

```text
01_ОСВ_входящие
```

Если в папке несколько файлов, программа возьмет самый новый файл `.xlsx`.

## 3. Как запустить отчет

Откройте PowerShell в папке проекта и выполните:

```powershell
python .\generate_report.py
```

После запуска готовый файл появится в папке:

```text
02_Готовые_отчеты
```

Название файла будет примерно таким:

```text
Отчет_по_ОСВ_ОСВ__20260609_1240.xlsx
```

## 4. Какие листы будут в отчете

### Отчет

Основной лист с управленческим балансом.

Структура:

- Активы;
- Обязательства;
- Собственный капитал;
- Итого пассивы и капитал;
- Контрольная строка.

Контрольная строка должна быть равна нулю:

```text
Активы - Пассивы и капитал = 0
```

### Расчет капитала

Лист показывает, как получился собственный капитал:

```text
Активы
- Обязательства
= Собственный капитал
- Уставный капитал
= Накопленная прибыль / убыток
```

Так видно, что уставный капитал учтен отдельно, а накопленный результат рассчитан понятно.

### Детализация ОСВ

На этом листе находятся строки ОСВ, которые программа прочитала из исходного файла.

### Настройка строк

На этом листе видно, какие счета используются для каждой строки управленческого баланса.

## 5. Как сейчас настроены статьи баланса

### Активы

- Денежные средства: счета `50`, `51`, `52`, `55`.
- Авансы поставщикам: счет `60.02`.
- Дебиторская задолженность покупателей: счет `62.01`.
- Подотчетные лица: счет `71` по дебету.
- Переплаты по налогам: счет `68` по дебету.
- Переплаты по страховым взносам: счет `69` по дебету.
- Запасы, товары и незавершенное производство: счета `10`, `11`, `20`, `21`, `23`, `25`, `26`, `41`, `43`, `44`.
- Внеоборотные активы: счета `01`, `03`, `04`, `08`.
- Прочие активы: счета `19`, `58`, `76`, `97`.

### Обязательства

- Задолженность перед поставщиками: счет `60.01`.
- Авансы покупателей: счет `62.02`.
- Налоги к уплате: счет `68` по кредиту.
- Страховые взносы к уплате: счет `69` по кредиту.
- Задолженность по зарплате: счет `70`.
- Кредиты и займы: счета `66`, `67`.
- Прочая кредиторская задолженность: счета `71`, `73`, `75`, `76`, `96`, `98`.

### Собственный капитал

- Уставный капитал: счет `80`.
- Накопленная прибыль / убыток: расчетная строка.

Формула:

```text
Накопленная прибыль / убыток = Активы - Обязательства - Уставный капитал
```

## 6. Как изменить настройки

Настройки лежат в файле:

```text
04_Настройки\report_lines.json
```

В нем можно менять:

- название строки;
- счета, которые входят в строку;
- способ расчета;
- комментарий в отчете.

Основные способы расчета:

- `end_debit` - конечное дебетовое сальдо;
- `end_credit` - конечное кредитовое сальдо;
- `end_debit_net` - дебет минус кредит;
- `end_credit_net` - кредит минус дебет;
- `turnover_debit` - дебетовый оборот;
- `turnover_credit` - кредитовый оборот;
- `equity_remainder` - расчет накопленной прибыли / убытка.

## 7. Что не нужно отправлять на GitHub

Не публикуйте реальные финансовые файлы:

- ОСВ из папки `01_ОСВ_входящие`;
- готовые отчеты из папки `02_Готовые_отчеты`;
- любые файлы с данными компании.

Они уже исключены из git через `.gitignore`.

## 8. Если отчет не сформировался

Проверьте:

1. Файл ОСВ лежит в папке `01_ОСВ_входящие`.
2. Файл имеет формат `.xlsx`.
3. ОСВ содержит строки вида `Счет, Наименование счета`.
4. В ОСВ есть колонки:

```text
Сальдо на начало периода
Обороты за период
Сальдо на конец периода
```

Если формат выгрузки из 1С изменится, нужно будет подстроить разбор в `generate_report.py`.
